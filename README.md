End-to-end data analysis project: Data Cleaning → EDA → Power BI Dashboard.

## 🛠️ Tools Used
Python (Pandas), SQL, Power BI (DAX, Slicers, Bookmarks)

## 📌 Project Phases
1. **Data Cleaning** – missing values, duplicates, outliers, feature engineering
2. **SQL** – fraud patterns across hours, merchants, age and amount
3. **Dashboard** – KPI cards, 6 charts, Age Group and Amount Range slicers

## 🔍 Key Insights
- 48.17% of 32,298 transactions were fraudulent
- High Risk merchants: 61.39% fraud rate vs 34.11% for Low Risk
- Ages 18–19 most targeted at 55.19%
- Fraud rate rises with amount, reaching 60.38% for 10K–20K
